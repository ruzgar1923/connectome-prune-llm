# ConnectomePrune: Meta LLaMA-3.2-1B-Instruct Playground

Interactive live demonstration of **ConnectomePrune-LLM**, created by 17-year-old student researcher **Rüzgar Vatansever** (Turkey).

Using whole-brain connectomics discovered in the adult fruit fly (*Nature*, 2024), 263.6 Million weights (27.10% linear sparsity) were pruned from Meta's official LLaMA-3.2-1B-Instruct model while maintaining 100% conversational reasoning, coding, and scientific factual accuracy.
